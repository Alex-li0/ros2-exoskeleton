# CPG 参数优化器改造工作报告

**日期**: 2025-05-11  
**修改范围**: `cpg_controller` 功能包

---

## 一、工作背景

原有的 CPG 参数优化器使用手工构造的正弦函数模拟人体步态轨迹，其谐波模型仅支持基频和二倍频（最多 3 阶谐波）。关节角度限位为硬编码值，与实际运动数据不匹配。C++ 控制器节点的 Hopf 振荡器积分存在数值误差，且缺乏对被动关节（踝关节）的灵活控制。

本次改造的目标是：引入真实人体步态运动捕捉数据，建立从数据到 CPG 控制器参数的自动化流水线。

---

## 二、改造内容

### 2.1 优化器：双数据源联合拟合

优化器采用两步联合工作流程：

**第一步：频率提取**  
读取"绝对时间完整值"数据（100Hz 采样，约 45 秒完整行走记录），通过行走段检测自动跳过首尾静止期，再用 FFT 分析得到真实步态主频及其角频率 ω。

**第二步：谐波权重拟合**  
读取"步态周期平均值"数据（200 个点代表一个归一化步态周期），用上一步得到的 ω 在 Hopf 振荡器极限环上等间隔采样 200 个点，构造特征矩阵，然后通过最小二乘法精确求解每个关节的谐波权重。

拟合模型从原来的 3 阶扩展到 4 阶（基频 + 二倍频 + 三倍频），以提高被动关节（踝关节）的拟合精度。踝关节拟合残差从约 5.5° 降低到约 1.9°。

### 2.2 关节角度坐标变换与限位推导

**膝关节符号修正**：人体运动捕捉数据中膝关节弯曲方向为正值，但 URDF 模型中为负值。优化器对膝关节数据自动取反，确保输出角度与机器人坐标系一致。

**数据驱动限位**：关节角度限位不再硬编码，而是从实际数据的最小值/最大值自动推导，外加 10% 裕量。例如膝关节数据范围为 [-64°, +2.6°]，对应限位 [-1.24, +0.16] 弧度。此前硬编码的 `limit_max: 0.0` 会导致膝关节正值被钳位为零，关节完全不动。

### 2.3 C++ 控制器数值积分修正

**显式欧拉 + 子步长**：原 C++ 代码每 10ms 控制周期只做一次欧拉积分，且存在 Gauss-Seidel 误差（先更新 x 再用于 y 的计算）。修改为 10 步子步长积分，每步 1ms，且显式保存 dx、dy 后再同时更新 x、y，与优化器的积分方式完全一致。

**高阶谐波生成**：新增三倍频谐波计算，使控制器能支持 `num_harmonics=4` 的踝关节参数。谐波生成公式与优化器的 OLS 特征矩阵一一对应。

### 2.4 踝关节控制开关

新增 `publish_ankle` 布尔参数：

- `true`（仿真模式）：command 和 joint_states 都输出 CPG 踝关节轨迹，用于可视化验证
- `false`（实机模式）：command 锁定踝关节为零位（被动关节不助力），joint_states 仍显示 CPG 轨迹（便于监控）

### 2.5 状态机过渡改进

**静止态输出**：IDLE 状态下所有关节输出 0（直立站立位），而非 w_offset。

**渐入渐出**：行走启动时，从 0 半余弦平滑过渡到完整 CPG 轨迹（包含 w_offset 振荡中心和所有谐波分量）。停止时反向过渡回 0。

## 三、输出文件管理

优化器输出的 YAML 配置文件和拟合对比图的文件名自动包含速度和试次编号：

- YAML：`cpgS{speed}T{trial}.yaml`
- 图片：`gait_fit_S{speed}_T{trial}.png`

不同速度对应不同的步频和关节运动幅度，方便对比和管理。

---

## 四、使用方法

```bash
# 默认速度 1.0 m/s, 试次 1
python3 src/cpg_controller/scripts/cpg_optimizer.py

# 指定速度和试次
python3 src/cpg_controller/scripts/cpg_optimizer.py --speed 1x5 --trial 3

# 只生成 YAML 不生成图片
python3 src/cpg_controller/scripts/cpg_optimizer.py --no-plot
```

## 五、关键参数说明

| 参数 | 说明 |
|------|------|
| w_offset | 步态周期内关节角度的时间平均值，作为 CPG 振荡的直流偏置中心 |
| w_x, w_y | 各阶谐波的 cos/sin 权重，决定振荡的幅值和相位 |
| num_harmonics | 谐波阶数：髋关节=2（基频），膝关节=3（+二倍频），踝关节=4（+三倍频） |
| limit_min/max | 从实际数据自动推导的关节安全限位，含 10% 裕量 |
| omega | 从绝对时间数据 FFT 分析得到的真实步态角频率 |
