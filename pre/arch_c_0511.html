SECTION 02

为什么选择架构 C

三种 CPG+NMPC 结合方式的对比

架构CPG 角色NMPC 角色优点缺点适用
A. 纯NMPC仅相位 φ(t)规划全部最灵活求解失败无保底仿真
B. 纯跟踪完整参考轨迹跟踪CPG简单安全地形适应有限平地
C. 骨架+修正⭐骨架轨迹+地形自适应调参CPG为参考，地形为约束，做最优修正安全+灵活+地形适应复杂度中等外骨骼

💡 架构 C 的核心思想

CPG 提供"生物学先验"——基于真实人体步态数据拟合的合理轨迹。NMPC 在此基础上做"微调"，而不是从零搜索。即使 NMPC 求解失败，系统可降级为纯 CPG 模式——直接执行骨架轨迹也不会出安全问题。

🔑 CPG 的关键价值

  • 保证步态的周期性和对称性（左右腿反相）
  • 权重已通过 OLS 拟合了真实人体步态数据
  • 提供可行的、安全的参考轨迹
  • 天然的双腿协调能力
  • 求解器失败时可安全降级为纯 CPG 模式

⚡ NMPC 的关键价值

  • 将地形信息转化为硬约束（脚必须落在地形表面）
  • 在关节力矩、ZMP 稳定性等物理约束下寻最优
  • 可偏离 CPG 参考轨迹以适应复杂地形
  • 每个控制周期重新求解，实时优化

🔗 三者如何协作——一句话总结

CPG 回答"步态应该长什么样" → 地形回答"脚该落在哪里" → NMPC 回答"关节该怎么动"

class TerrainFeatureExtractor(Node):
  def extract_along_trajectory(self, gridmap, pos, heading):
    # 1. 沿行走方向采样前方 1-2 个步长
    line = sample_gridmap(gridmap, start=pos, dir=heading, len=2.0)

    # 2. 计算地形特征
    height_profile = line['elevation']    # 高度剖面
    slope = np.gradient(height_profile)     # 坡度
    roughness = np.std(height_profile)     # 粗糙度
    traversability = line['traversability'] # 可通过性

    # 3. 计算最优落脚点
    foot_z = find_optimal_foot_placement(height_profile, slope)

    return TerrainFeature {height_profile, slope, foot_z, traversability}

⚡ NMPC 优化问题定义 需新建

minimize  J = Σt [ w₁ · ‖q(t) - qcpg(t)‖² ← 跟踪 CPG 参考（软约束）
              + w₂ · ‖τ(t)‖²        ← 能耗最小
              + w₃ · ‖CoM(t) - CoMref(t)‖² ← 质心稳定性 ]

subject to:
  ① M(q)·q̈ + C(q,q̇)·q̇ + G(q) = τ + Jᵀ·Fext ← 动力学方程
  ② qmin ≤ q ≤ qmax          ← 关节限位
  ③ |τ| ≤ τmax             ← 力矩限位
  ④ zfoot(x,y) = elevation(x,y)      ← 地形接触约束（来自高程图）
  ⑤ q(t) 相位与 CPG 同步        ← 步态节奏约束
  ⑥ ZMP ∈ 支撑多边形          ← 不摔倒

SECTION 08

CPG 核心算法详解

基于 Hopf 振荡器 + 傅里叶级数映射的步态生成

💓 Hopf 主振荡器

二维极限环微分方程，生成稳定的周期振荡信号：

ẋ = γ(μ - r²)x - ωy
ẏ = γ(μ - r²)y + ωx

其中 r² = x² + y², μ=极限环半径², γ=收敛速度, ω=角频率
参数当前值作用地形自适应
μ1.0振幅基准固定
ω6.28 (1Hz)步频上坡减速，下坡控制
γ15.0收敛速度固定

🎵 傅里叶级数关节映射

将振荡器的 (x,y) 映射为各关节角度，膝关节使用基频+二倍频塑造双峰：

θhip(t) = whx·x + why·y + offset
θknee(t) = wkx1·x + wky1·y + wkx2·(x²-y²) + wky2·(2xy) + offset
θankle(t) = wax·x + way·y + offset

权重通过 OLS 最小二乘法拟合真实人体步态数据（cpg_optimizer.py）

⛰️ 地形自适应参数调节 需增强

根据 Terrain Extractor 输出的坡度和粗糙度，动态调节 CPG 参数：

// 在 legs_cpg.cpp 的 on_timer() 中新增
void adjust_cpg_for_terrain(const TerrainFeature& terrain) {
  double slope = terrain.avg_slope;       // 正=上坡，负=下坡
  double roughness = terrain.roughness;  // 地形粗糙度

  // 1. 步频调节：上坡减速
  omega_ = base_omega_ * (1.0 - 0.3 * clamp(slope, -0.3, 0.3));

  // 2. 步幅调节：粗糙地形减小步幅
  mu_ = base_mu_ * (1.0 - 0.5 * clamp(roughness, 0.0, 0.5));

  // 3. 髋关节偏移：上坡抬高腿
  joints_["left_hip3"].w_offset = base_hip_off_ + 0.2 * max(slope, 0.0);

  // 4. 踝关节角度：上坡背屈、下坡跖屈
  joints_["left_ankle"].w_offset = base_ankle_off_ + 0.15 * slope;
}

import casadi as ca

# 定义优化变量
Q = ca.MX.sym('Q', n_joints, N)  # 关节角度序列
Qd = ca.MX.sym('Qd', n_joints, N) # 关节角速度
Tau = ca.MX.sym('Tau', n_joints, N)# 关节力矩

# 代价函数
cost = 0
for k in range(N):
  cost += w1 * ca.sumsqr(Q[:,k] - Q_cpg[:,k])  # CPG跟踪
  cost += w2 * ca.sumsqr(Tau[:,k])      # 能耗

# 约束
g = []
for k in range(N-1):
  g.append(dynamics(Q[:,k], Qd[:,k], Tau[:,k]) - [Q[:,k+1], Qd[:,k+1]])
  g.append(terrain_height(Q[foot_idx,k]) - elevation_lookup(foot_xy[:,k]))

# 求解
nlp = {'x': X, 'f': cost, 'g': ca.vertcat(*g)}
solver = ca.nlpsol('solver', 'ipopt', nlp)

🎮 RL 与 CPG 的交互机制

RL 不直接控制关节，而是调节 CPG 的参数——低维、安全的动作空间。

📥 状态空间 State (输入)

  • 关节角度 q、角速度 q̇（来自 /joint_states）
  • 地形特征：坡度、粗糙度（来自 Terrain Extractor）
  • CPG 相位 φ = atan2(y, x)（来自 CPG 振荡器）
  • 人体意图向量（来自 VINS 位姿分析）
  • CPG 当前参数 (ω, μ, w_offset, w_x, w_y)

📤 动作空间 Action (输出)

  • Δω — 步频微调（±10%）
  • Δμ — 步幅微调（±10%）
  • Δw_offset — 各关节偏移微调
  • Δw_x[i], Δw_y[i] — 谐波权重微调
  • 动作被 NMPC 层安全过滤后执行
