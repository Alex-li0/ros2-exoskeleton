01设计原则

🎯 CPG 的定位

CPG 始终是轨迹生成器，NMPC 始终是修正器。区别只在于修正量的大小——平地时 NMPC 修正量小，复杂地形时修正量大。

⏱️ 权重切换时机

权重切换是离散的、以步态周期为边界的。过渡发生在步与步之间（摆动腿落地瞬间），不是步态内部的连续变化。

🔄 在线学习

在线学习包括频率自适应和振幅自适应，基于 Hopf 振荡器的 Hebbian 学习机制。Hebbian 权重学习暂时关闭（η=0），待上机后激活。

📡 NMPC 协作

NMPC 检测到地形变化后，在当前步结束时通知 CPG 切换 gait mode。NMPC 的优化结果可作为 CPG 的"教师信号"。

P0启停状态机 + 振幅调制

🔒 目标

让 CPG 能安全地启动和停止，而不是永远在极限环上运转。
改动范围：legs_cpg.cpp · cpg.yaml

状态机设计

enum CPGState { IDLE // A=0, 输出零 STARTING // A: 0→1 渐入 WALKING // A=1, 全振幅 STOPPING // A: 1→0 渐出 }

振幅调制

// 关节输出乘以振幅因子 theta_output = A(t) * theta_cpg // A(t) 平滑渐变 STARTING: A += dt / ramp_time STOPPING: A -= dt / ramp_time

✅ 验收标准

发布 /cpg/state_cmd 为 stop 后，CPG 输出在 ramp_time 内平滑归零；发布 start 后输出平滑恢复。

P3谐波阶数自适应

🎵 不同地形需要不同精度的波形拟合

地形模式膝关节谐波数踝关节谐波数原因
flat_walk2~3 阶2 阶波形平滑，基频+二倍频足够
stair_up4~5 阶3 阶膝关节屈曲 ~90°，波形更尖锐
stair_down4~5 阶3 阶需要主动缓冲，波形复杂
slope_up3 阶2~3 阶髋关节抬高，波形略复杂
slope_down3 阶2~3 阶踝关节背屈增大

⚙️ 实现方式

每种 gait mode 的每个关节已有独立的 num_harmonics（P1 中定义）。运行时取当前 mode 中所有关节的最大谐波数作为实际计算阶数。

P4在线频率 + 振幅学习

📊 频率自适应

ω̇ = -ε · F(t) · y/r
  • F(t)：关节力矩误差或地面反力
  • ε：耦合强度（0.1~0.5）
  • y/r：CPG 相位正弦分量
  • LPF 平滑：τ · ω̇_smooth + ω_smooth = ω_raw

📈 振幅自适应

α̇ = η · F(t) · x/r
  • η：振幅学习率
  • x：CPG 位置（与 y 正交）
  • μ = max(μ_min, α)
  • LPF 平滑消除高频振荡

🔬 理论依据

基于 datasheet/Hopf/cpg.tex 的完整推导：
• 耦合强度 ε 与收敛速度正相关，与稳态精度负相关
• LPF 打破"快收敛 vs 稳态噪声"的死结
• 多干扰信号时，CPG 自动锁定最近频率（积分器滤除高频）

✅ 验收标准

改变外部激励频率后，CPG 的 ω 能在数个步态周期内收敛到新频率；负载变化时振幅自动调整。
